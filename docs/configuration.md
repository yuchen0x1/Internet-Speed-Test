# 配置与数据

## 数据目录

Windows 桌面版使用 Tauri 的应用数据目录：

```text
%APPDATA%\com.netvisionpro.app
```

当前用户的实际路径可以在“设置与关于”页的“关于”区域查看。主要文件包括：

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 应用设置和自定义节点。 |
| `history.db` | SQLite 测速历史和详情。 |
| `settings.json.bak` | 设置文件损坏时，应用自动备份的旧文件。 |
| `settings.json.bak.1` 等 | 已有备份时使用的后续恢复点，不覆盖较早备份。 |

设置采用原子写入。首次运行或设置文件不存在时使用默认值；解析失败时先备份为 `settings.json.bak`，再恢复默认设置。

CLI 在 Windows 上复用 `%APPDATA%\com.netvisionpro.app`。如果没有 `APPDATA` 环境变量，CLI 会回退到系统临时目录下的 `netvision-pro-cli`。

## 默认设置

以下值来自 v1.9.0 的 Rust 默认配置：

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 主题 | 深色 | 可选深色、浅色、跟随系统。 |
| 动画效果 | 开启 | 关闭后减少过渡和动效。 |
| 数据刷新频率 | 1 秒 | 监控图表刷新间隔。 |
| 节点选择 | 自动优选 | 综合延迟、可用性和下载能力。 |
| 测速持续时间 | 10 秒 | 下载与上传各执行一段。 |
| 精度模式 | 关闭 | 开启后增加并发和采样。 |
| 下载并发 | 6 | 范围 1–16。 |
| 上传并发 | 4 | 范围 1–8。 |
| 自动保存历史 | 开启 | 完成、取消、失败均按状态入库。 |
| 后台监控 | 开启 | 1 秒采样网卡流量。 |
| 状态栏流量 | 开启 | 显示当前收发速率。 |
| 开机自启 | 关闭 | 写入当前用户 Run 项。 |
| 计划测速 | 关闭 | 默认间隔 60 分钟。 |
| 桌面通知 | 开启 | 计划测速及网络断开/恢复通知。 |
| 阈值告警 | 关闭 | 默认阈值 200 ms，目标 `223.5.5.5`。 |
| 历史保留 | 90 天 | 启动时清理超过保留期的记录。 |
| Prometheus | 关闭 | 开启后默认端口 9876。 |
| 显示公网 IP | 关闭 | 关闭时不查询公网地址。 |
| 保存诊断数据 | 开启 | 诊断结果保存在本机会话。 |
| 关闭到托盘 | 关闭 | 关闭按钮默认退出窗口。 |

## Prometheus / Grafana

设置页开启“Prometheus / Grafana 指标导出”后，端点监听：

```text
http://127.0.0.1:9876/metrics
```

端口可改为 1024–65535。端点只绑定本机回环地址，不对局域网开放。修改端口或开关后，应用会自动应用新的端点状态。

指标来自本地历史和网络状态。应用未开启该设置时，不会启动端点。

- `netvision_tests_total`：现存历史总条数（包括失败、取消），TYPE 为 gauge；删除和保留策略会使它下降，不要使用 rate/increase。
- `netvision_history_completed`、`netvision_history_failed`、`netvision_history_cancelled`：各状态现存条数，均为 gauge。
- `netvision_last_*`：最近成功测速的速度、延迟、抖动、丢包和时间；未知上传/丢包省略。连续失败时保留上次成功值，请结合 timestamp 和失败条数判断新鲜度。
- `netvision_last_test_timestamp` 为 Unix 秒数，旧本地时间按本地时区转换；无法确定时省略样本。

兼容提示：v1.13.0 修正了计数的 TYPE（原来误标 counter）和最近值口径，现有 Grafana 查询应按上述说明复查。见 [本轮报告](evolution-batch-metrics-2026-11-13.md)。

HTTP 只提供 GET `/metrics`，错误路径 404、非 GET 405、读取历史库失败 503。最多处理 16 个并发请求，超额连接直接关闭；头上限 8KiB、读头超时 2 秒、整体处理上限 5 秒。

## 隐私开关

- 关闭“显示公网 IP 与 ISP”时，应用不向服务查询公网 IP。
- 开启后仅使用测速同源服务获取相关信息。
- NDT7 的访问令牌只在 Rust 连接适配器运行时使用，不写入设置、前端状态、CLI JSON 或历史详情。
- 导出文件由本机生成；分享前请自行检查其中的节点、时间和网络字段。

## 自定义节点

自定义节点保存于 `settings.json`，节点页要求 HTTPS。测速引擎会对节点地址进行校验，不接受 `file:`、`javascript:` 或任意非 HTTPS 地址。

建议使用可控的 LibreSpeed 服务，并确认其 `empty.php`、下载和上传端点可从本机访问。节点可用性取决于服务端配置和当前网络线路。

## 重置配置

1. 退出 NetVision Pro。
2. 备份 `%APPDATA%\com.netvisionpro.app\settings.json` 和 `history.db`。
3. 删除或重命名 `settings.json`。
4. 重新启动应用，设置会恢复默认值。

删除 `history.db` 会永久删除测速历史；如需保留记录，请先在历史页导出 CSV/JSON 或生成 HTML 报告。
